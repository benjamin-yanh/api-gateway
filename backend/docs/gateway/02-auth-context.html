Token 是访问凭证，不是模型 Token。状态、过期、IP、模型白名单和额度共同决定是否继续。

可配置项

字段影响
group、cross_group_retry渠道范围、auto 跨组重试。
model_limits、状态/过期/IP模型和来源限制。
分组 total/success、ModelRequestRateLimitDurationMinutes429 窗口，Redis→内存降级。

常见误解与自检

  • 401 是凭证问题，403 是权限/指定渠道问题，429 先查本地限流。
  • 普通 Token 不绑定单一渠道。
  • 用 user_id、token_id、group、request_id 串起日志。
