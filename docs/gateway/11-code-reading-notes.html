关键上下文不变量

  • specific_channel_id 只代表管理员指定渠道；普通分发会继续走能力、分组和亲和性判断。
  • relayInfo 保存一次请求的模型、渠道、估算 Token、PriceData、Billing 和重试索引；不要跨请求复用。
  • 重试必须重新装载渠道上下文并复位 BodyStorage；否则下游会读到空 Body 或旧 Header。
  • 预扣和结算是两个阶段；异常路径必须退款或记录违规扣费，不能只看 HTTP 成功。
  • 所有用户可控计费乘数都必须先验证上限，再进入价格表达式和 quota 转换。
