协议入口与下游能力矩阵

入口协议由 Router 注册，统一进入 Relay；下游协议由 APIType/ChannelType 和 Adaptor 决定。标记为 RelayNotImplemented 的路径会返回未实现错误，不应当当作可用能力宣传。

客户端接入注意

  • Claude 的 x-api-key、Gemini 的 query/header key、Realtime 子协议都会在 TokenAuth 归一为 Bearer。
  • 请求体必须可重复读取，重试前由 BodyStorage 复位；自定义客户端不要依赖一次性不可重放流。
  • 是否支持 stream_options 取决于渠道能力，不要仅凭入口协议推断。
  • 同一入口可映射多个供应商；供应商差异应在 Adaptor 层解决。
