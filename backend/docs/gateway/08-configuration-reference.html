配置参考：从哪里调、何时生效

本页只列影响网关请求链路的参数。默认值和生效阶段均从代码推导；后台配置是否持久化取决于 GlobalConfig/数据库加载流程。

阅读方法

“来源”决定在哪里修改；“生效阶段”决定会不会影响当前请求；“安全风险”提示不要把内部密钥或不受限倍率暴露给调用方。

环境变量通常在进程初始化时读取；请求字段由客户端每次提供；渠道字段和 GlobalConfig 设置可能热加载。部署前请以当前版本的启动日志和控制台为准。

每请求可调字段（非系统配置）

model、stream、max_tokens/max_completion_tokens/max_output_tokens、temperature、group、prompt_cache_key、metadata.user_id、图片 n、任务时长等会影响模型选择、Token 估算或计费。校验器会限制计费乘数；不要绕过标准 DTO 通过 Extra 或 multipart 传入未校验的数量。

运维在渠道管理中调整 type、Base URL、Key、模型映射、分组、优先级、权重、启用状态、auto-ban、多 Key、参数/请求头覆盖及自定义路由。选择和上下文写入见 model/channel_cache.go、middleware/distributor.go:SetupContextForSelectedChannel。
