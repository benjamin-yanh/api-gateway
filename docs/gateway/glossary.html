网关术语表

先给学习者一个可操作的定义，再给维护者对应的代码对象。

总览配置协议排障源码导读
术语通俗解释代码中的边界
网关 Gateway替客户端统一接入多个 AI 供应商的服务。Router→Middleware→Controller→Relay→Adaptor。
Relay把一次调用串起来的转发核心。controller/relay.go 与 relay/*。
Channel 渠道一个可用的上游服务配置。model.Channel；有类型、Key、URL、模型能力、组、优先级、权重。
Adaptor 适配器把统一请求翻译成供应商协议。relay/channel/adapter.go 接口及各实现。
APIType/RelayFormat分别描述下游接口类型和网关内部处理格式。由 relay.GetAdaptor 与路由 handler 关联。
Token调用网关的访问凭证。决定用户、额度、分组、模型限制；不是模型输入 Token。
模型 Token输入/输出文本或媒体的计费单位。本地估算或上游 Usage；进入预扣和结算。
Group渠道和价格策略的逻辑分组。Token group、using group、auto group 可能不同。
渠道亲和性相同业务 Key 在 TTL 内尽量复用同一渠道。Key→Channel ID 缓存；规则含 path/model/key source/skip retry。
指定渠道管理员在 Token 后追加渠道 ID，强制本次请求使用该渠道。sk-key-channelID 解析到 specific_channel_id；失败不切换。
优先级/权重先选优先级，再在同级按权重分流。CacheGetRandomSatisfiedChannel。
RetryParam记录一次请求的渠道重试进度。service/channel_select.go；不等同 HTTP 客户端重试。
BodyStorage可重复读取的请求体存储。重试前复位 Body，支持内存或磁盘缓存。
预扣 Pre-consume上游调用前先冻结预计额度。PreConsumeBilling；不等于最终消费。
结算 Settlement按真实 Usage 补扣或退款。SettleBilling/BillingSession。
RelayNotImplemented路由存在但处理能力尚未实现。controller.RelayNotImplemented 明确返回错误。
Usage供应商返回的实际用量。缺失时可能回退到本地估算。
ContextGin 请求范围内的共享状态袋。保存 user/token/group/channel/override/retry/billing 信息。
